# 🐱 Catwar — 냥냥 방위대

바퀴벌레, 개미, 모기, 거미, 생쥐 같은 침입자들이 귀여운 소녀의 집으로 몰려옵니다!
반치즈 코리안숏헤어 **치즈**가 이끄는 냥냥 방위대가 집을 지킵니다.
동네 코숏들과 여러 품종 고양이를 **수집하고 레벨업·성급을 올려 스킬을 키우는** 브라우저용 2D 횡스크롤 라인 디펜스 게임입니다.
설치 없이 PC와 모바일 브라우저에서 바로 플레이할 수 있습니다.

> 현재 버전은 **플레이 가능한 프로토타입**입니다. 그래픽은 외부 에셋 없이 전부 Canvas 코드로 그렸습니다.

## 실행 방법

Node.js 18 이상이 필요합니다.

```bash
npm install       # 의존성 설치
npm run dev       # 개발 서버 (http://localhost:5173, 같은 Wi-Fi의 휴대폰에서도 접속 가능)
npm run build     # 타입 체크 + 프로덕션 빌드 (dist/)
npm run preview   # 빌드 결과 미리보기
```

`dist/`는 정적 파일이라 GitHub Pages, Netlify 등 아무 정적 호스팅에나 올리면 됩니다.

## 게임 구조

```
로비 ─┬─ 🗺️ 스테이지: 10개 스테이지 (현관 → 거실 → 부엌 → 다락방), 클리어 시 별 1~3개
      ├─ 🐱 고양이: 도감, 레벨업(🪙 코인), 성급 업(조각) → 스킬 강화
      ├─ 🧩 편성: 주인공 치즈 + 고양이 최대 4마리
      └─ 📦 상자 뽑기: 🥫 참치캔으로 고양이 뽑기
          ↓ 출전
전투 ── 츄르로 고양이 소환, 치즈 액티브 스킬, 웨이브 방어 → 보상 획득 → 로비
```

### 성장 시스템
- **레벨업**: 🪙 코인을 써서 체력·공격력을 올립니다. 레벨 상한 = 10 + 성급 × 10.
- **성급(★1~5)**: 뽑기에서 이미 가진 고양이가 나오면 조각 +10. 조각을 모아 성급을 올리면 **스킬 레벨**과 능력치, 레벨 상한이 올라갑니다.
- **주인공 치즈**는 뽑기에 나오지 않습니다. 스테이지를 클리어할 때마다 치즈 조각을 얻습니다.
- **재화**: 🪙 코인(스테이지 보상, 반복 클리어 가능) / 🥫 참치캔(첫 클리어, 새로 얻은 별).
- **뽑기**: 1회 🥫100, 10회 🥫900(SR 이상 1마리 확정). 확률: SSR 3% · SR 12% · R 35% · N 50%.
- 진행 상황은 브라우저 `localStorage`에 자동 저장됩니다.

### 고양이 도감 (13종)

| 고양이 | 품종 | 등급 | 역할 | 스킬 |
| --- | --- | --- | --- | --- |
| **치즈** 👑 | 반치즈 코숏 | 주인공 | 리더 | 📣 꾹꾹이 응원: (직접 사용) 아군 전체 회복 + 공격력 증가 |
| 고등어 | 고등어태비 코숏 | N | 탱커 | 🛡️ 식빵 굽기: 받는 피해 감소 |
| 흰둥이 | 흰 코숏 | N | 원거리 | 🎯 털뭉치 난사: N번째 공격마다 사거리 안 모든 적 공격 |
| 카오스 | 카오스 코숏 | N | 돌격 | 💨 우다다 몸통박치기: 강타 + 밀쳐내기 |
| 치즈태비 | 치즈태비 코숏 | R | 근접 | 🌀 뒹굴뒹굴 회오리: 주변 광역 강타 |
| 턱시도 | 턱시도 코숏 | R | 암살 | 💥 신사의 일격: 치명타 |
| 삼색이 | 삼색 코숏 | R | 지원 | 💗 그루밍: 가장 다친 아군 회복 |
| 블루 | 러시안 블루 | SR | 원거리 | ❄️ 차가운 눈빛: 적중한 적 감속 |
| 폴드 | 스코티시 폴드 | SR | 탱커 | 💫 동글 박치기: 기절 |
| 먼치 | 먼치킨 | SR | 돌격 | 🔥 짧은 다리 폭주: 체력 50% 이하일 때 공격 속도 증가 |
| 페르 | 페르시안 | SR | 지원 | ✨ 우아한 기품: 주변 아군 공격력 증가 |
| 쿤 | 메인쿤 | SSR | 광역 탱커 | 💨 거대 냥펀치: 광역 강타 + 밀쳐내기 |
| 샴 | 샴 | SSR | 저격 | 🎯 사파이어 스나이프: 사거리 안 모든 적 저격 |

치즈는 전투 시작 시 자동으로 출전하고, 쓰러지면 15초 뒤 복귀합니다.

### 침입자

| 이름 | 특징 |
| --- | --- |
| 개미 | 약하지만 떼로 몰려옴 |
| 바퀴벌레 | 매우 빠름 |
| 모기 | 날아다님 |
| 생쥐 | 기본 적 |
| 거미 | 거미줄을 쏘는 원거리 공격 |
| 대왕쥐 👑 | 보스. 광역 공격 (기절·감속 효과가 덜 먹힘) |

스테이지가 올라갈수록 적의 체력과 공격력이 강해집니다(x1.0 → x3.2).

### 조작

| 동작 | 터치 / 마우스 | 키보드 |
| --- | --- | --- |
| 고양이 소환 | 하단 고양이 버튼 | `1` ~ `4` |
| 치즈 스킬 | 하단 치즈 버튼 | `Q` |
| 지갑 업그레이드 | 왼쪽 아래 지갑 버튼 | `W` |
| 일시정지 / 나가기 | 오른쪽 위 `Ⅱ` | `P` / `Esc` |
| 배속(x1 / x2) | 오른쪽 위 `x1` | `F` |

로비는 세로 화면에 맞춰져 있고, 전투 화면은 휴대폰을 세로로 들고 있으면 자동으로 90° 회전해 화면을 꽉 채웁니다. 전투 중에는 휴대폰을 가로로 돌려서 플레이하세요.

## 프로젝트 구조

```
src/
  data/
    cats.ts      고양이 도감 (능력치, 스킬, 외형)
    skills.ts    스킬 효과 수치와 설명 (성급별)
    enemies.ts   침입자 능력치
    stages.ts    스테이지, 웨이브, 보상
    config.ts    전투 공통 설정
  meta/
    save.ts        저장/불러오기 (localStorage)
    progression.ts 레벨업, 성급 규칙
    gacha.ts       상자 뽑기
    rewards.ts     스테이지 보상과 해금
  game.ts      전투 시뮬레이션 (이동, 타겟팅, 전투, 스킬, 웨이브, 승패)
  catdraw.ts   고양이 외형 그리기 (무늬: 반치즈/고등어/턱시도/삼색/카오스/포인트 등)
  render.ts    전투 화면 렌더링
  ui.ts        전투 버튼 레이아웃
  menu.ts      로비 화면 (DOM)
  main.ts      화면 전환, 게임 루프, 입력, 화면 회전
  style.css    로비 스타일
```

- 기술 스택: **TypeScript + Vite + HTML5 Canvas 2D**. 런타임 의존성은 없고, 웹폰트(Jua)만 Google Fonts에서 불러옵니다.
- 전투는 Canvas, 로비 메뉴는 DOM으로 만들어 스크롤과 반응형 레이아웃이 자연스럽습니다.
- 밸런스 조정은 `src/data/` 안의 숫자만 바꾸면 됩니다.
- 개발 중 브라우저 콘솔에서 `__catwar`로 상태에 접근할 수 있습니다 (예: `__catwar.save.tuna = 9999; __catwar.setSave(__catwar.save)`).
