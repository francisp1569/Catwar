# 🐱 Catwar — 냥냥 방위대

바퀴벌레, 개미, 모기, 거미, 생쥐 같은 침입자들이 귀여운 소녀의 집으로 몰려옵니다!
반치즈 코리안숏헤어 **치즈**가 이끄는 냥냥 방위대가 집을 지킵니다.
동네 코숏들과 여러 품종 고양이를 **수집하고 키워서**, 위에서 몰려오는 벌레 떼를 바리케이드 뒤에서 막아내는 **세로형 서바이버 디펜스** 브라우저 게임입니다.
설치 없이 PC와 모바일 브라우저에서 바로 플레이할 수 있습니다.

> 현재 버전은 **플레이 가능한 프로토타입**입니다. 그래픽은 외부 에셋 없이 전부 Canvas 코드로 그렸습니다.

## 실행 방법

Node.js 18 이상이 필요합니다.

```bash
npm install       # 의존성 설치
npm run dev       # 개발 서버 (http://localhost:5173, 같은 Wi-Fi의 휴대폰에서도 접속 가능)
npm run build     # 타입 체크 + 프로덕션 빌드 (dist/)
npm run preview   # 빌드 결과 미리보기
```

`dist/`는 정적 파일이라 GitHub Pages, Netlify 등 아무 정적 호스팅에나 올리면 됩니다.

## 게임 구조

```
로비 (하단 5탭)
 ├─ 🏪 상점   : 오늘의 무료 상자, 골판지 상자 뽑기(고양이), 집사 장비 상자
 ├─ 🎒 가방   : 집사 장비 6칸 장착, 인벤토리, 장비 강화·합성·분해, 재료 가방
 ├─ ⚔️ 전투   : 스테이지 미리보기(좌우 넘기기), 별 보상 상자, START, 낮잠 보상, 편성
 ├─ 🐱 고양이 : 큰 캐릭터 화면(좌우 넘기기), 레벨업·성급, 스킬, 앨범, 출전/대기, 도감 보너스
 └─ 🗺️ 지도   : 스테이지 목록 (현관 → 거실 → 부엌 → 다락방)
          ↓ START
전투 ── 세로 화면, 위에서 벌레·쥐 떼가 내려오고 아래 바리케이드 뒤 고양이들이 자동 공격
```

### 집사 장비
- 6부위: 📿 목걸이(공격력) · 🎀 모자(바리케이드 체력) · 🧸 장난감(공격 속도) · 🛏️ 방석(받는 피해 감소) · 🥣 밥그릇(전투 경험치) · 🔔 방울(코인 획득)
- 장착한 장비는 **모든 고양이**에게 적용됩니다. 등급 N/R/SR/SSR.
- 획득: 스테이지 클리어(1~3개), 상점 장비 상자, 오늘의 무료 상자
- 강화: 🪙 코인 + 🧶 털실. **일괄 합성**: 같은 부위·같은 등급 3개 → 한 단계 높은 등급. **분해**: 털실로 돌려받기
- **도감 보너스**: 모은 고양이 수와 성급만큼 모든 고양이 공격력 증가
- **낮잠 보상**: 시간이 지나면 코인과 털실이 쌓임 (최대 8시간, 클리어한 스테이지가 많을수록 많이)
- **집사 레벨**: 전투할 때마다 경험치

### 전투
- 화면 위쪽 구멍에서 침입자 무리가 내려와 바리케이드를 공격합니다. **바리케이드 체력이 0이 되면 패배**.
- 제한 시간을 버티면 마지막 무리(또는 보스 대왕쥐)가 나오고, 모두 물리치면 **승리**.
- 고양이들은 자동으로 공격합니다. 처음엔 **치즈 혼자** 싸우고, 편성한 고양이(최대 5마리)는 레벨업 때 NEW 카드로 하나씩 합류합니다.
- 적을 쓰러뜨려 경험치가 차면 **레벨 업 → 스킬 카드 3장 중 1장 선택**:
  - **NEW**: 편성한 고양이가 바리케이드 뒤로 뛰어 들어와 합류
  - **갈래형 강화**: 고양이마다 2~5갈래 (예: 냥냥펀치 "펀치 연타: 개수+1, 피해-15%" / "젤리 강화" / "꾹꾹 연사" / "관통 펀치")
  - 공용 카드: 🍡 츄르 간식(바리케이드 회복), 🐟 참치 파워(공격력), 🌿 캣닢 흥분(공격 속도)
  - 마음에 안 들면 **스킬 갱신**(전투당 2회)
- **집사 지원 출동**: 가끔 로봇청소기가 한 줄을 쓸고 지나갑니다.
- 레퍼런스처럼 처음엔 한두 마리씩, 시간이 갈수록 폭발적으로 몰려옵니다 (스테이지 2분 30초~4분 18초).
- **꾹꾹이 응원**(오른쪽 아래 치즈 버튼): 바리케이드 수리 + 잠시 모든 고양이 공격 속도 증가.
- 모든 편성 고양이의 체력 합이 바리케이드 체력이 됩니다. 탱커를 넣으면 버티기 쉬워져요.

### 성장 시스템
- **레벨업**: 🪙 코인을 써서 공격력과 바리케이드 체력 기여도를 올립니다. 레벨 상한 = 10 + 성급 × 10.
- **성급(★1~5)**: 뽑기에서 이미 가진 고양이가 나오면 조각 +10. 조각을 모아 성급을 올리면 능력치와 레벨 상한이 올라갑니다. 치즈의 성급은 응원 스킬도 강화합니다.
- 전투 중 스킬 레벨(Lv.1~5)은 매 전투마다 새로 시작합니다.
- **주인공 치즈**는 뽑기에 나오지 않습니다. 스테이지를 클리어할 때마다 치즈 조각을 얻습니다.
- **재화**: 🪙 코인(스테이지 보상, 반복 클리어 가능) / 🥫 참치캔(첫 클리어, 새로 얻은 별).
- **뽑기**: 1회 🥫100, 10회 🥫900(SR 이상 1마리 확정). 확률: SSR 3% · SR 12% · R 35% · N 50%.
- 진행 상황은 브라우저 `localStorage`에 자동 저장됩니다.

## 프로젝트 구조

```
src/
  data/
    cats.ts      고양이 도감 (능력치, 외형)
    weapons.ts   고양이별 전투 스킬 Lv.1~5 수치·설명, 공용 카드, 응원 스킬
    enemies.ts   침입자 능력치
    stages.ts    스테이지 (시간, 출현량, 적 구성, 몰려오는 무리, 보스, 보상)
    config.ts    전장 레이아웃, 경험치 곡선
  meta/
    save.ts        저장/불러오기 (localStorage)
    progression.ts 레벨업, 성급 규칙
    gacha.ts       상자 뽑기
    rewards.ts     스테이지 보상과 해금
  game.ts      전투 시뮬레이션 (출현, 이동, 스킬 발동, 경험치·카드 선택, 승패)
  catdraw.ts   고양이 그리기: 옆모습(로비·카드)과 뒷모습(전투), 무늬별 표현
  render.ts    전투 화면 렌더링
  ui.ts        전투 화면 버튼 레이아웃
  menu.ts      로비 화면 (DOM)
  main.ts      화면 전환, 게임 루프, 입력, 화면 맞춤
  style.css    로비 스타일
```

- 기술 스택: **TypeScript + Vite + HTML5 Canvas 2D**. 런타임 의존성은 없고, 웹폰트(Jua)만 Google Fonts에서 불러옵니다.
- 전투는 Canvas, 로비 메뉴는 DOM으로 만들어 스크롤과 반응형 레이아웃이 자연스럽습니다.
- 밸런스 조정은 `src/data/` 안의 숫자만 바꾸면 됩니다.
- 개발 중 브라우저 콘솔에서 `__catwar`로 상태에 접근할 수 있습니다 (예: `__catwar.save.tuna = 9999; __catwar.setSave(__catwar.save)`).
