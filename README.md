# 🐱 Catwar — 냥냥 방위대

바퀴벌레, 개미, 모기, 거미, 생쥐 같은 침입자들이 귀여운 소녀의 집으로 몰려옵니다!
고양이들을 소환해서 집을 지켜내는 **브라우저용 2D 횡스크롤 라인 디펜스 게임**입니다.
설치 없이 PC와 모바일 브라우저에서 바로 플레이할 수 있습니다.

> 현재 버전은 **플레이 가능한 프로토타입**입니다. 그래픽은 외부 에셋 없이 전부 Canvas 코드로 그렸습니다.

## 실행 방법

Node.js 18 이상이 필요합니다.

```bash
npm install       # 의존성 설치
npm run dev       # 개발 서버 실행 (http://localhost:5173, --host 로 같은 Wi-Fi의 휴대폰에서도 접속 가능)
npm run build     # 타입 체크 + 프로덕션 빌드 (dist/)
npm run preview   # 빌드 결과 미리보기
```

`dist/` 폴더는 정적 파일이므로 GitHub Pages, Netlify 등 아무 정적 호스팅에나 올리면 됩니다 (`base: './'` 설정).

## 게임 방법

- **왼쪽**: 소녀의 집(기지). 체력이 0이 되면 패배합니다.
- **오른쪽**: 벽에 난 쥐구멍. 침입자들이 웨이브 단위로 쏟아져 나옵니다.
- **츄르(🐟)** 가 시간이 지나면 자동으로 차오릅니다. 적을 처치해도 츄르를 얻습니다.
- 하단 버튼으로 츄르를 써서 고양이를 소환하세요. 소환 후엔 재소환 대기시간이 있습니다.
- **지갑 업그레이드**: 츄르 최대치와 충전 속도가 올라갑니다 (최대 Lv.6).
- 7개의 웨이브를 모두 막아내면 **승리**!

### 조작

| 동작 | 터치 / 마우스 | 키보드 |
| --- | --- | --- |
| 고양이 소환 | 하단 고양이 버튼 | `1` `2` `3` `4` |
| 지갑 업그레이드 | 왼쪽 아래 지갑 버튼 | `W` |
| 일시정지 | 오른쪽 위 `Ⅱ` | `P` / `Esc` |
| 배속(x1 / x2) | 오른쪽 위 `x1` | `F` |

휴대폰을 세로로 들고 있으면 게임 화면이 자동으로 90° 회전되어 화면을 꽉 채웁니다. 휴대폰을 가로로 돌려서 플레이하세요.

## 프로젝트 구조

```
src/
  data.ts    유닛·적·웨이브·밸런스 수치 (밸런스 조정은 여기서)
  game.ts    게임 상태와 시뮬레이션 (이동, 타겟팅, 전투, 투사체, 웨이브, 승패)
  render.ts  Canvas 렌더링 (배경, 집, 소녀, 고양이, 벌레, UI, 오버레이)
  ui.ts      버튼 레이아웃과 터치 판정
  main.ts    게임 루프, 화면 스케일링/회전, 터치·키보드 입력
```

- 기술 스택: **TypeScript + Vite + HTML5 Canvas 2D** (런타임 의존성 없음, 빌드 결과 JS 약 10KB gzip)
- 논리 해상도 960×540을 화면 크기에 맞춰 확대/축소하고(레터박스), 고해상도(DPR) 화면에서도 선명하게 그립니다.
- 시뮬레이션(`game.ts`)과 렌더링(`render.ts`)이 분리되어 있어, 나중에 스프라이트 이미지로 교체하기 쉽습니다.
- 개발 중 브라우저 콘솔에서 `__game`으로 게임 상태에 접근할 수 있습니다 (예: `__game.churu = 999`).
